Política de Privacidade

Lendas de Valdoria

Esta Política de Privacidade descreve como o jogo Lendas de Valdoria coleta, utiliza, armazena e protege os dados pessoais dos jogadores, em conformidade com a Lei Geral de Proteção de Dados Pessoais (LGPD - Lei n. 13.709/2018).

1. Controlador dos Dados

Responsavel: Raphael Redes (desenvolvedor independente)
Contato: contato@lendasdevaldoria.com.br
Localizacao: Brasil

2. Dados Coletados

Coletamos os seguintes dados através da interacao com o bot do Telegram:

  • Identificador do Telegram (user ID): Numero unico atribuido pelo Telegram, usado para vincular seus dados de jogo
  • Nome de usuario do Telegram: Usado apenas para exibicao no jogo
  • Dados de personagem: Nome, classe, raca, atributos, inventario, progresso de missoes, histórico de combate e demais informações de jogo
  • Historico de jogo: Acoes realizadas, conquistas, estatisticas de combate, exploracoes e interacoes com NPCs
  • Dados de sessao: Informacoes temporarias de navegacao dentro do jogo (tela atual, estado de combate, etc.)
  • Dados de compra: Registros de transacoes via Telegram Stars (nenhum dado financeiro e armazenado por nos)

3. Dados NAO Coletados

  • Nao coletamos dados financeiros (cartoes, contas bancarias)
  • Nao coletamos dados de localizacao geografica
  • Nao coletamos contatos ou agenda do dispositivo
  • Nao coletamos fotos, arquivos ou midias do dispositivo
  • Nao compartilhamos dados com terceiros para fins publicitarios

4. Finalidade do Tratamento

Os dados sao utilizados exclusivamente para:

  • Funcionamento do jogo (salvar progresso, personagens, inventario)
  • Identificacao do jogador dentro do sistema do jogo
  • Suporte tecnico e resolucao de problemas
  • Melhorias no jogo baseadas em dados agregados e anonimizados

5. Base Legal (Art. 7, LGPD)

O tratamento de dados e realizado com base no consentimento do titular (Art. 7, I), manifestado ao iniciar o uso do bot com o comando /start, e para execução de contrato (Art. 7, V), sendo necessario para a prestacao do serviço de jogo.

6. Armazenamento e Seguranca

  • Os dados sao armazenados em banco de dados SQLite com criptografia em repouso
  • Backups automaticos sao realizados periodicamente
  • O acesso aos dados e restrito ao desenvolvedor e a sistemas automatizados do jogo
  • A comunicacao entre o bot e o Telegram utiliza HTTPS (criptografia em transito)

7. Retencao dos Dados

Os dados de jogo sao mantidos enquanto o jogador possuir uma conta ativa. Apos solicitacao de exclusao, os dados sao removidos em ate 30 dias uteis, exceto quando houver obrigacao legal de retencao.

8. Direitos do Titular (Art. 18, LGPD)

Voce tem direito a:

  • Confirmacao e acesso: Saber quais dados temos sobre voce
  • Correcao: Solicitar correcao de dados incompletos ou desatualizados
  • Exclusao: Solicitar a exclusao dos seus dados pessoais
  • Portabilidade: Solicitar seus dados em formato estruturado
  • Revogacao do consentimento: Retirar o consentimento a qualquer momento
  • Oposicao: Opor-se ao tratamento de dados em determinadas situacoes

Para exercer seus direitos, entre em contato pelo e-mail: contato@lendasdevaldoria.com.br

9. Cookies e Armazenamento Local

O jogo utiliza localStorage do navegador (dentro do Telegram Mini App) para:

  • Salvar preferencias de interface (aba ativa, modo imersivo, volume)
  • Cache de dados de sessao para melhorar desempenho
  • Identificacao de sessao do dispositivo (device lock)

Nao utilizamos cookies de rastreamento ou analiticos de terceiros.

10. Transferencia Internacional

Os dados podem ser processados em servidores localizados fora do Brasil (Google Cloud, Cloudflare). Nesses casos, garantimos que os provedores adotam medidas de protecao equivalentes as exigidas pela LGPD.

11. Menores de Idade

O jogo e destinado a maiores de 16 anos. Não coletamos intencionalmente dados de menores de 16 anos. Caso tome conhecimento de que um menor utilizou o serviço sem consentimento dos responsaveis, entre em contato para que possamos tomar as providências cabíveis.

12. Alteracoes nesta Política

Esta politica pode ser atualizada periodicamente. Alteracoes significativas serao comunicadas através do bot do Telegram. A continuidade de uso apos as alteracoes constitui aceitação da nova versao.
