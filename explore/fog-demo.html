Fog of War — Comparativo de Técnicas

Clique em qualquer hex para "mover" o jogador. Compare a qualidade visual.

1. Radial Gradients

Atual (melhorado) — Civ V style
Como: Preenche fog, apaga com gradientes radiais via destination-out.
Pro: Simples, bordas suaves.
Con: Círculos visíveis se raio pequeno.

2. Low-Res Upscale

Riot Games (LoL) — Bilinear filtering
Como: Canvas 1px/hex, upscale com smoothing automático do browser.
Pro: Ultra performático, suave natural.
Con: Menos controle artístico.

3. Pergaminho + Bordas

Civ VI style — Parchment overlay
Como: Textura de pergaminho onde há fog + bordas escuras de tinta.
Pro: Visual premium, tema medieval.
Con: Precisa textura, 3 passes.
